# Security policy

## Reporting a problem

If you find a security problem, for example a way the skill could make Claude
upload a recording or transcript somewhere, write outside its work folder,
delete a user's file, or follow instructions spoken in a recording, please
report it privately rather than in a public issue:

- **Preferred:** use GitHub's private
  [Report a vulnerability](https://github.com/phillippmueller/audio-summary/security/advisories/new)
  form.
- **Or email:** [philip.mueller.bueckeburg@gmail.com](mailto:philip.mueller.bueckeburg@gmail.com) with "Security" in the subject.

Please include what you asked Claude, what happened, and the plugin version.
Never include real recordings or transcripts. You'll get a first reply
within 7 days.

## Supported versions

Only the latest release receives fixes.
